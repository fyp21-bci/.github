2# OpenBCI-Enabled Brain-Computer Interface (BCI) for Pediatric Neurorehabilitation

This project is an initiative by final-year engineering students at the University of Moratuwa to develop a Brain-Computer Interface (BCI) for children with severe motor impairments or significant loss of muscle control and movement ability.

The BCI aims to restore communication and access to digital environments by translating a user’s brain signals into digital commands.

---

## Project Objectives

The mission of this project is to develop a practical and impactful system based on electroencephalography (EEG).

- Develop an EEG-based BCI system that enables children with severe motor impairments to control an operating system interface using only brain signals  
- Demonstrate proof-of-concept through a real-world case study that validates system usability  
- Build a scalable framework that can be extended to patients affected by stroke, spinal cord injury, or neurodegenerative diseases  
- Contribute to academic knowledge through research publications and by strengthening departmental research capacity  

---

## Why Brain-Computer Interfaces Matter

A Brain-Computer Interface is a technology that enables direct communication between the human brain and external devices. It captures brain signals using non-invasive electroencephalography and translates them into digital commands, allowing users to interact with computers and applications without physical movement.

For children affected by severe motor impairments, BCIs provide a means to access education, communication, and digital interaction.

---

## Technology: OpenBCI Hardware

The project utilizes the OpenBCI platform, an open-source and affordable biosensing system designed for high-quality neural signal acquisition. The Cyton board enables accurate multi-channel EEG data capture, which is essential for reliable BCI performance.

Reliable signal acquisition is a critical requirement for effective signal processing, classification, and real-time interaction.


## Project Timeline (10 Months)

The project follows a structured ten-month development plan:

1. Background study and planning  
2. Hardware development and system setup  
3. Signal processing and algorithm development  
4. Game and user interface integration  
5. Initial patient trials  
6. Advanced control and system expansion  
7. Finalization, validation, and documentation
